Welcome to bun-starter

A production-ready starting template for Bun web applications

Introduction

bun-starter is an application to be used as a starting template for other production applications. The pages are intended to illustrate usage. For instance View All Countries illustrates a GET API call, Search Countries illustrates a GET API call passing a parameter whilst the product pages illustrate POST API calls.

Tech Stack

  • Bun 1.3.4 - JavaScript runtime
  • Lit - Web components framework
  • SQLite - Persistent storage
  • Tailwind CSS - Styling
  • better-auth - Authentication
  • marked - Markdown to HTML

Key Features

Authentication: Uses better-auth library for in-house applications with admin-managed users and passwords.
Database Setup: Included script creates SQLite database, better-auth tables, default admin user, and test data for countries and products.
Content Management: File system based multi-category page system with auto-generated index pages (blogging/documentation style). Pages display "latest first" and support flags for private, draft, reading mode, and sticky.
File Uploads: Upload images and *.md content files.
Search: Full-text search system built in using FTS5.
Custom Image Component: Better control over image wrapping, positioning, and sizing.
Spellcheck: Built-in spellcheck for markdown content.

Platform Notes

The focus is desktop application development. Although the app is responsive, some UI work may look a little off on mobile (suggested fixes welcome).
